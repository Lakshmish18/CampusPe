Claude Chat UI Clone

A frontend chat interface inspired by Claude.ai, built as a static web project.  
It includes a left sidebar, responsive top navigation, welcome suggestion cards, chat message rendering, typing simulation, dark mode toggle, and chat export support.

Technologies Used

- HTML5
- CSS3
- JavaScript
- jQuery
- Bootstrap 5
- Font Awesome

File Structure


.
├─ index.html
├─ css/
│  └─ style.css
├─ js/
│  └─ chat.js
└─ README.md


 How to Run

1. Open the project folder.
2. Open `index.html` directly in your browser.

Optional: for best local script/style loading behavior, run a simple local server and open the served URL.
